# Constitución de Humanity.wiki

Versión 1.1

## Propósito
Define las reglas fundamentales de Humanity.wiki.

## Principios
1. Todo pertenece al grafo de conocimiento.
2. Toda entidad tiene autor.
3. Toda entidad pertenece a un territorio.
4. Toda modificación genera historial.
5. Toda entidad tiene UUID permanente.
6. El conocimiento no se elimina por accidente: se archiva y queda recuperable. **Pero quien lo creó puede pedir su borrado definitivo**; entonces pasa a una papelera durante 15 días y después se elimina de verdad, con todo lo que dependa de ello. (Modificado por Eugenio el 2026-08-08; antes decía «Nunca se elimina conocimiento».)
7. Evitar duplicados.
8. Relaciones explícitas.
9. Flujo: Problema → Conocimiento → Soluciones → Necesidades → Productos → Transacción → Iniciativa → Resultados → Caso de éxito.
10. Diseñar siempre para escalar.
