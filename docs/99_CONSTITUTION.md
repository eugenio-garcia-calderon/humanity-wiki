# Constitución de Red Humana

Versión 1.0

## Propósito
Define las reglas fundamentales de Red Humana.

## Principios
1. Todo pertenece al grafo de conocimiento.
2. Toda entidad tiene autor.
3. Toda entidad pertenece a un territorio.
4. Toda modificación genera historial.
5. Toda entidad tiene UUID permanente.
6. Nunca se elimina conocimiento.
7. Evitar duplicados.
8. Relaciones explícitas.
9. Flujo: Problema → Conocimiento → Soluciones → Necesidades → Productos → Transacción → Iniciativa → Resultados → Caso de éxito.
10. Diseñar siempre para escalar.

## Prioridad
Constitución > Visión > Arquitectura > Base de datos > Requisitos > UI > Implementación.
