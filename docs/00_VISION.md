# Visión de Conocimiento de la Humanidad

## Misión
Permitir comprender retos, coordinar recursos y ejecutar iniciativas.

## Componentes
- Grafo de conocimiento
- Red social
- Marketplace
- Economía colaborativa
- Indicadores
- Territorios
- Casos de éxito

## Flujo
Problema → Conocimiento → Soluciones → Necesidades → Productos → Transacción → Iniciativa → Resultados → Caso de éxito → Nuevo conocimiento.

## Objetivos
Agua, Alimentación, Vivienda, Salud, Convivencia, Ecosistemas, Educación, Movilidad, Energía, Tecnología y Empleo.
