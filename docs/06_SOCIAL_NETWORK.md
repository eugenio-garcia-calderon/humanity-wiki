# 06_SOCIAL_NETWORK.md

# Sistema de Red Social

## Objetivo

Definir el funcionamiento de la red social integrada en Conocimiento de la Humanidad.

---

# Filosofía

La red social existe para generar conocimiento útil y acelerar la resolución de retos.

No está diseñada para maximizar tiempo de uso.

Está diseñada para maximizar impacto.

---

# Tipos de usuario

## Nivel 1 - Usuario

Puede:

- Crear cuenta
- Editar perfil
- Publicar contenido
- Comentar
- Reaccionar
- Seguir usuarios
- Guardar publicaciones

## Nivel 2 - Usuario verificado

Además puede:

- Crear retos
- Crear soluciones
- Crear productos
- Crear demandas
- Editar contenido dentro de su ámbito territorial

## Nivel 3 - Generador de conocimiento

Además puede:

- Revisar contenido
- Solicitar revisiones
- Añadir notas de veracidad
- Publicar en cualquier territorio

## Nivel 4 - Administrador

Acceso total.

---

# Perfil

Cada usuario dispone de:

- Foto
- Nombre
- Biografía
- Formación
- Especialidades
- Territorios
- Organización
- Redes
- Estadísticas
- Nivel
- Impacto generado

---

# Publicaciones

Una publicación puede contener:

- Texto
- Imágenes
- Vídeos
- Documentos
- Enlaces

Puede asociarse a:

- Territorios
- Objetivos
- Indicadores
- Marcadores
- Retos
- Soluciones
- Productos
- Demandas
- Iniciativas
- Casos de éxito

---

# Interacciones

- Comentarios
- Respuestas
- Reacciones
- Compartir
- Guardar
- Seguir

---

# Feed

El contenido se prioriza por:

- Territorio
- Objetivos seguidos
- Indicadores relacionados
- Personas seguidas
- Relevancia
- Calidad

---

# Búsqueda

Permite buscar:

- Personas
- Organizaciones
- Publicaciones
- Retos
- Soluciones
- Productos
- Demandas
- Iniciativas

---

# Trazabilidad

Toda publicación conserva:

- Autor
- Fecha
- Versiones
- Historial

---

# Moderación

El contenido puede:

- Ser reportado
- Solicitar revisión
- Ser archivado
- Mantener historial completo

---

# Integración

Las publicaciones aparecen automáticamente en las fichas de las entidades relacionadas para enriquecer el ecosistema de conocimiento.
