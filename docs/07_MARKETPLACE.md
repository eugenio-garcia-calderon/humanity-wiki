# 07_MARKETPLACE.md

# Mercado de Red Humana

## Objetivo

Definir el funcionamiento del mercado integrado en el ecosistema de conocimiento.

---

# Filosofía

El mercado existe para facilitar la resolución de retos.

No es un ecommerce independiente.

Toda oferta y demanda debe estar vinculada al grafo de conocimiento.

---

# Entidades

- Producto
- Demanda
- Necesidad
- Pedido
- Transacción
- Vendedor
- Comprador

---

# Productos

Cada producto incluye:

- Nombre
- Descripción
- Categoría
- Físico o digital
- Pago único o recurrente
- Precio
- Garantía
- Stock (opcional)
- Autor
- Organización
- Territorios
- Objetivos relacionados
- Indicadores relacionados
- Retos relacionados
- Soluciones relacionadas

---

# Demandas

Cada demanda incluye:

- Descripción
- Prioridad
- Presupuesto
- Territorio
- Objetivos relacionados
- Estado
- Autor

Estados:

- Abierta
- En negociación
- Cubierta
- Cancelada

---

# Necesidades

Una necesidad puede resolverse mediante:

- Producto
- Servicio
- Donación
- Voluntariado
- Organización
- Financiación

---

# Flujo

Reto

↓

Solución

↓

Necesidad

↓

Demanda

↓

Producto

↓

Compra

↓

Iniciativa

↓

Resultados

↓

Caso de éxito

Secciones:

- Filtros

---

# Filtros

- Territorio
- Objetivo
- Indicador
- Precio
- Tipo
- Disponibilidad

---

# Stripe

Todas las compras utilizan Stripe.

Funciones:

- Checkout embebido
- Reembolsos
- Suscripciones
- Stripe Connect
- Facturación

---

# Valoraciones

Compradores pueden valorar:

- Producto
- Vendedor

Las valoraciones nunca eliminan el historial.

---

# Integración

Cada producto aparecerá automáticamente en:

- Retos relacionados
- Soluciones relacionadas
- Iniciativas relacionadas
- Casos de éxito relacionados
- Publicaciones relacionadas

El mercado forma parte del grafo de conocimiento.
