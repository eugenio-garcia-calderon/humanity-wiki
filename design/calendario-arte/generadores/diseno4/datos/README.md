# datos

- `canonical_face_model.obj` — MediaPipe's canonical 3D face (468 vertices, 898 triangles,
  centimetres; x to the subject's left on screen, y up, z toward the viewer). From
  https://github.com/google/mediapipe/blob/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj
  (Apache License 2.0, © Google LLC). Used by `retrato.py` so a painted face has the
  structure of a real one: brow, sockets, cheekbones, nose, lips and jaw where they are.
